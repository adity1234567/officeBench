1. What was run

The Bangla translations in batch_1..5.csv are WorkBench templates (T01–T69). OfficeBench has only email (list, read, send to one recipient), calendar (create, delete by exact title, list; no attendees, no edit), Excel, Word, PDF, OCR, shell and an LLM app. It has no CRM, analytics or project-management app, so only 11 templates map onto OfficeBench's apps without workarounds. They were run as OfficeBench tasks:

  • T16: the template says "my first free slot from tomorrow" but never says when the workday starts. 08:00 is a defensible reading; my grader assumed 09:00. All three Bangla T16 runs chose 09:30 and passed.
  • T20: OfficeBench events have no attendee field, so adding the person's name to the title is a reasonable way to record "with Dana". Time and duration were correct in both languages.
  • T15.v1 BN is the only failure where the action itself is wrong. The model treated "the next meeting with Dana" as every upcoming meeting with Dana. The other two Bangla phrasings of T15 passed.
Counting the four grader-assumption failures as passes gives English 33/33 and Bangla 32/33. Either way, the difference between languages is one run or fewer.

Correction to an earlier claim. I first said the delete_event bugs affected your earlier 300-task OfficeBench scores. The bugs matter only for tasks like the WorkBench templates, where 8 of the 11 templates delete events.

5.3 Run history

  • A pilot (T10.v1) failed in both languages and exposed the two delete_event bugs. Every T10 run made before the fix was deleted and rerun.
  • One restart was wasted by my own mistake: the patched apps were copied to /apps_patched instead of /apps. Those runs were deleted and rerun.
  • The machine rebooted at 04:19 because memory and disk ran out (C: dropped to 0.02 GB free; Windows paging file on C:). After the reboot, Docker Desktop would not start until stale socket files in AppData\Local\Docker\run and docker-secrets-engine were moved aside. The WSL swap file was moved to D:\WSL and the WSL VM capped at 4 GB.
  • The run resumed at 05:26 and finished at 05:40. None of the 66 graded runs has a harness error; finished runs were never rerun.

6. Limits

  • Small and easy: 33 runs per language on the 11 simplest templates; the model is near the ceiling, so the run cannot show a gap of a few points (WorkBench's 90-task interval already allows up to about 8 points).
  • One run per cell at temperature 0; run-to-run variation is not measured.
  • My slot values, starting data and grader. Different choices (for example a 08:00 workday) would change T16 and T20.
  • Translations: the Bangla text is taken from the CSVs unchanged. It uses ASCII digits (for example "30 মিনিটের"), and person and event names stay in Latin script. Native-speaker review is still pending, as in the WorkBench study.
